# Cactus Espresso Bar — website concept

Адаптивний демонстраційний сайт кав'ярні **Cactus Espresso Bar** у Києві.

## Адреса та контакти
- Київ, вул. Патріарха Мстислава Скрипника, 5
- Телефон: +380 99 764 11 02
- Години: пн–пт 08:00–21:00; сб–нд 09:00–21:00
- Instagram: https://www.instagram.com/cactus_espresso_bar_/ (посилання з публікації 2019 року; перед релізом перевірити чинність)

## Можливості
- Responsive layout: mobile, tablet, desktop
- П'ять категорій меню з цінами на основі наданої фотографії
- Динамічний статус відкриття закладу за київським часом
- Кнопка телефону, маршрут у Google Maps, інтерактивна карта
- SEO, Schema.org, доступна клавіатурна навігація, анімації з підтримкою reduced motion
- Auto-deploy через GitHub Pages workflow

## Розміщення
Файли статичні, без збірки. Відкрийте `index.html` або увімкніть GitHub Pages у налаштуваннях репозиторію (джерело — GitHub Actions).

## Важливо перед публікацією
Сайт наразі **демонстраційний**, не офіційний.
1. Усі ціни та години слід підтвердити у власника.
2. Фотографії закладу для демо завантажуються із зовнішніх матеріалів [The Village Україна (2019)](https://www.village.com.ua/village/food/food-news/290385-kav-yarnya-cactus-espresso-bar-bilya-pivdennogo-vokzalu) та [Blackfield Coffee (2019)](https://blackfield.coffee/10-novih-kav-yaren-zhovtnya/). Для комерційного використання потрібен дозвіл правовласників або власні фотографії. Зовнішні зображення можуть змінитися чи перестати завантажуватись.
3. Рейтинг 4.8/5 (69 відгуків) — з наданого скриншота; він не оновлюється автоматично.
4. Перевірити актуальність Instagram.
5. У майбутньому змінити повідомлення про демонстраційність у футері, коли власник затвердить сайт.

Built with HTML, CSS & vanilla JS.
